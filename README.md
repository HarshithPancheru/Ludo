# Ludo Game

A simple Ludo game built using **HTML, CSS, and plain JavaScript**, developed as a hands-on project to explore and understand the HTML Canvas API.

The entire game is implemented from scratch without using any external libraries or frameworks. From drawing the board and game pieces to handling movements and animations, everything is managed using native JavaScript and Canvas.

## Features

- **Canvas Rendering:** Game board, tokens, and other visual elements are drawn directly onto the HTML Canvas.
- **Animations:** Smooth animations for token movements and game interactions.
- **Custom Game Logic:** Game mechanics and movement logic implemented from scratch.
- **No External Libraries:** Built entirely with vanilla JavaScript, HTML, and CSS.
- **Interactive Gameplay:** User interactions handled through native JavaScript event listeners.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Canvas API

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone git@github.com:HarshithPancheru/Ludo.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Ludo
   ```

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.

## Purpose

This project was primarily built to gain practical experience with the HTML Canvas API and understand how graphical elements can be rendered and animated using JavaScript.

It explores concepts such as:
- Canvas drawing and rendering.
- Coordinate systems and positioning.
- Animation loops and frame updates.
- Event handling and user interactions.
- Implementing game logic without relying on external libraries.
